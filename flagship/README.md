# Flagship - Backend Chatbot DevOps

Ce dossier contient le projet fil rouge.

Il démarre en Mission 3 avec une API FastAPI et PostgreSQL, puis grossit avec Docker, CI/CD, VPS, monitoring, LLM externe, GCP, Terraform et Kubernetes optionnel.

## Structure Prévue

```txt
flagship/
├── app/
├── migrations/
├── ansible/
├── k8s/
├── evidence/
└── .github/
```

Les fichiers applicatifs seront ajoutés mission par mission.
