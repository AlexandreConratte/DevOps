# EXERCICES 01 - LINUX, TERMINAL ET SSH

Ce dossier contient les exercices de la fiche `fiches/01_Linux_Terminal_SSH.md`.

Ne pas chercher a tout faire parfaitement au debut.

Objectif : manipuler, noter les commandes, comprendre les erreurs, puis committer.

Pour une version plus guidee, suivre d'abord [TP_LINUX_COMPLET.md](TP_LINUX_COMPLET.md).

## Exercices a faire

- [ ] Navigation : creer `devops/linux/lab`, entrer dedans, creer `notes.txt`.
- [ ] Lecture : ecrire 5 lignes dans `notes.txt`, lire avec `cat`, `head`, `tail`.
- [ ] Droits : creer `hello.sh`, le rendre executable, lancer `./hello.sh`.
- [ ] Processus : lancer une commande longue puis retrouver son PID avec `ps`.
- [ ] Logs : creer un faux `app.log`, le suivre avec `tail -f`.
