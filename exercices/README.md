# EXERCICES DEVOPS

Ce dossier sert a stocker les travaux pratiques.

Organisation conseillee :

```txt
exercices/
|-- 01_linux/
|-- 02_reseau/
|-- 03_git/
|-- 04_scripts/
|-- 05_docker/
|-- 06_cicd/
|-- 07_deploiement/
|-- 08_terraform/
|-- 09_kubernetes/
|-- 10_monitoring_securite/
`-- 11_databases_yaml/
```

Ne pas tout creer a l'avance.

Creer seulement le dossier du sujet en cours, puis committer le travail progressivement.

Pour le jour 0, seul `exercices/01_linux/` est initialise.

Chaque exercice doit contenir au minimum :

- un `README.md` ou `reponses.md`;
- les commandes lancees;
- les resultats observes;
- les erreurs rencontrees;
- ce qui a ete compris.

Fin de semaine :

- verifier `SUIVI_PROGRESSION.md`;
- ajouter une entree dans `JOURNAL_APPRENTISSAGE.md`;
- garder uniquement des preuves utiles : commandes, resultats, erreurs, correction;
- faire un commit propre.
