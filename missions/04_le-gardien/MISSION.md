# Mission 4 - Le Gardien

Statut : squelette à compléter.

## 🎯 Le Brief

Créer une pipeline CI au push : lint, tests, build Docker, scan, publication d'image.

## ✅ Definition Of Done

- [ ] Pipeline GitHub Actions verte.
- [ ] Tests et lint lancés automatiquement.
- [ ] Image Docker construite.
- [ ] Trivy et gitleaks intégrés.
- [ ] Dependabot actif.
- [ ] Incident secret simulé et documenté.

## 🤖 IA Dans Cette Mission

Utiliser l'IA pour analyser une pipeline rouge ou relire une PR. La CI et les scans restent la source de vérité.
