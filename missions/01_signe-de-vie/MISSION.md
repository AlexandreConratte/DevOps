# Mission 1 - Signe De Vie

Statut : squelette à compléter.

## 🎯 Le Brief

Mettre en ligne un serveur HTTP minimal sur un VPS et le rendre persistant après reboot.

## ✅ Definition Of Done

- [ ] VPS accessible en SSH.
- [ ] Service HTTP joignable publiquement.
- [ ] Service géré par systemd.
- [ ] Redémarrage serveur testé.
- [ ] Preuve déposée dans `flagship/evidence/`.

## 🤖 IA Dans Cette Mission

Utiliser l'IA pour formuler des hypothèses de debug sur `journalctl`, ports et firewall. La source de vérité reste les commandes de diagnostic.
