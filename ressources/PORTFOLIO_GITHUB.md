# Portfolio GitHub DevOps Junior

Objectif : rendre le travail lisible pour un recruteur en moins de 3 minutes.

## README Du Projet Fil Rouge

Le README doit montrer :

- ce que fait l'application ;
- l'architecture ;
- les commandes de lancement local ;
- le lien public si disponible ;
- les étapes CI/CD ;
- les captures importantes ;
- les incidents simulés ;
- les choix techniques ;
- ce qui reste à améliorer.

## Preuves À Montrer

- pipeline verte ;
- image Docker publiée ;
- app en HTTPS ;
- dashboard Grafana ;
- alerte ou incident simulé ;
- postmortem court ;
- `terraform plan` ou preuve de teardown ;
- extrait d'usage IA corrigé et validé.

## Profil GitHub

Le profil doit expliquer en quelques lignes :

- objectif stage/alternance ;
- stack travaillée ;
- projet principal ;
- façon de travailler : Git, CI, Docker, monitoring, documentation.

## CV

Préférer des bullets orientés preuves :

- "Déploiement d'une API FastAPI/PostgreSQL en HTTPS sur VPS avec Nginx."
- "Pipeline GitHub Actions : tests, lint, build Docker, Trivy, gitleaks."
- "Monitoring Prometheus/Grafana avec incident simulé et postmortem."
- "Infrastructure GCP décrite avec Terraform et teardown documenté."

Ne pas lister un outil si aucun livrable ne le prouve.
