# Équivalences Cloud

GCP est le cloud principal du parcours. Ce fichier aide à reconnaître les noms AWS et Azure.

| Besoin | GCP | AWS | Azure |
| --- | --- | --- | --- |
| Conteneur serverless | Cloud Run | App Runner / ECS Fargate | Container Apps |
| Registre d'images | Artifact Registry | ECR | Azure Container Registry |
| Permissions | IAM | IAM | Entra ID / RBAC |
| Base PostgreSQL managée | Cloud SQL | RDS | Azure Database for PostgreSQL |
| Secrets | Secret Manager | Secrets Manager | Key Vault |
| Logs/monitoring | Cloud Logging/Monitoring | CloudWatch | Azure Monitor |

Le but n'est pas de tout apprendre en parallèle, mais de savoir traduire les concepts.
