# Glossaire DevOps

Glossaire recruteur-friendly. À compléter au fil des missions.

| Terme | Explication simple |
| --- | --- |
| CI | Vérification automatique du code à chaque changement |
| CD | Déploiement ou préparation au déploiement automatisé |
| Reverse proxy | Service qui reçoit les requêtes web et les transmet au bon backend |
| Migration | Changement versionné de la structure d'une base de données |
| Infrastructure as Code | Description de l'infrastructure avec du code |
| HPA | Mécanisme Kubernetes qui ajuste le nombre de pods selon la charge |
